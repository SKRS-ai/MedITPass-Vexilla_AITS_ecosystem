Authentication

All requests to the MedPass™ API must be signed with a Vexilla Bearer Token. Tokens are generated via the Vexilla Auth portal and are bound to your hardware-specific API key.

Authorization: Bearer VX_LIVE_8832_ALPHA_KEY

The Handshake Listener

To receive a 3-second data burst from a physical ScribeBoard™ terminal, your application must listen for the Handshake.Success event.

POST /v1/handshake/init

Triggers a proximity request to the patient's device.

{ "terminal_id": "SB-229-ROOM-A", "request_scopes": ["allergies", "medications", "surgical_history"], "encryption_mode": "KYBER_PQ_STRICT" }

The "Sovereign Query"

Because MedPass™ is Zero-Knowledge, you cannot "search" a database. You must request a **Sovereign Query** where the patient's device computes the answer and sends the result.

GET /v1/vault/validate-medication?drug=Penicillin

Returns a boolean based on the patient's hardware-encrypted allergy list.
